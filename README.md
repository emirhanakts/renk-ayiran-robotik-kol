# renk-ayiran-robotik-kol
Nesneleri renklerine göre ayırıp ilgili bölmelere yerleştiren robotik kol projesi.

# Renk Ayıran Robotik Kol

Bu projenin amacı, farklı renklerdeki nesneleri bir robotik kol yardımıyla
otomatik olarak ayırmaktır.

## Çalışma mantığı
Sistem nesnenin rengini belirler. Robotik kol nesneyi alır ve algılanan
renge karşılık gelen bölmeye bırakır.
